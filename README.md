# Industrial-Quality-Failure-Prediction

End-to-end ML project to predict industrial quality failures using sensor data, with EDA, model development, and deployment plan.

### Project Goal
Predict Quality Failure (0/1) using sensor data like Temperature, Pressure, Flow, Vibration.

### Week 3 - ML Model Plan
- **Models:** Logistic Regression, Decision Tree, Random Forest
- **Split:** 80:20 Stratified
- **Validation:** 5-Fold Cross Validation + GridSearchCV
- **Metrics:** Precision, Recall, F1-Score, ROC-AUC
- **Deployment:** Flask API with model.pkl

### Tech Stack
Python, Pandas, Scikit-Learn
